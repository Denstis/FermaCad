# Раскрой: торцы, запилы, вложение

Раскройная вкладка (F4) строит таблицу резов по каждому стержню и суммарную
спецификацию заготовок. Основа — **единое ядро `cutCore()`** (28-calc.js),
которое классифицирует конец стержня и считает геометрию запила; те же
данные используют обёртки `cutEndData`/`endInfo` (таблица текста и 3D-призмы
в 29-fullmodel.js). До v53 логика была продублирована в двух местах с
расходящимися порогами.

## Классы концов

| Класс | Условие | Рез | Вынос в Ls |
|---|---|---|---|
| `flat` | узел-опора | торец под 90° | 0 |
| `pass` | продолжение того же стержня (угол >165° к соосному соседу) | без запила, проходной | 0 |
| `main` | стержень сам является осью проходного стыка (pair соосных) | целый (основной) | 0 |
| `free` | нет соседей | свободный край, без запила | 0 |
| `T` | ветвь упирается в main (ветвь не влезает в полость) | впритык к наружной стенке, e = sOut | **−e** |
| `nest` | сечение ветви ≤ полости main (hollow, 2 стенки) | **вложение**: depth до противоположной внутренней стенки, e = sFar | **−e** |
| `miter` | угловой стык двух непарных направлений | запил по биссектрисе | **+e** |

**Знак выноса (`endLenAdd`, шаг 4б):** у `miter` край заготовки выходит ЗА
узел (остриё запила по биссектрисе) → `+e`; у `T`/`nest` конец НЕ доходит до
оси на `e` (впритык к стенке / вложение в полость — ровно тем `min(e,.45L)`
обрезает призму `buildFullModel`) → `−e`. `Ls = La + endLenAdd(A) + endLenAdd(B)`.

## Геометрия глубины (детектор коллизий)

Короб стержня‑основы в плоскости его сечения: `W×H` (для rhs — с учётом
конвенции «широкая сторона вертикально»), полость `W−2t × H−2t`.
Луч вдоль оси ветви `v` через box:

- `sOut = min(W/2|α|, H/2|γ|)` — наружная стенка (стык впритык);
- `sFar = min((W−2t)/2|α|, (H−2t)/2|γ|)` — дальняя внутренняя стенка полости
  (глубина вложения).

Ветка входит в полость, если `min(bB,hB) ≤ min(W−2t,H−2t)` и
`max(bB,hB) ≤ max(W−2t,H−2t)`. Полная 3D‑модель («Профили») обрезает призму
ветви по этим глубинам — **ничего не выпирает за наружные стенки**; сварное
кольцо рисуется по торцу/наружной стенке.

## Угловые стыки (miter)

Правило биссектрисы: угол между осями α → рез θ = 90° − α/2
(прямой угол 90° → запил 45°). Вынос запила ≈ (h/2)·ctg(α/2)
с проекцией по ширине стенки.

## T-стык

Основной стержень (по массе сечения из соосной пары) — целый;
ветвь режется (подрез), вынос = половина габарита main по направлению реза.

## Узлы и проверки сборки (v53)

- **`nodeJoints()`** — классификация узлов: support/empty/free/pass/T/K/X/N/
  corner, приоритет «кто главный» (опора > сквозной стык > ветви), кэш
  `calc.joints`.
- **`assemblyPlan()`** — 6 этапов (столбы → нижний пояс → стойки → верхний
  пояс → прогоны/связи → укосины), жадная поэтапная установка; кэш
  `calc.plan`. Проверки:
  - `float` — деталь «висит в воздухе» (конец не соединён с установленным);
  - `collide` — коллизии тел (`segClosest`, тиры по вписанной/описанной
    полуокружности сечения); подсказка: пересечение в поле без узла →
    инструмент X;
  - `tight` — вплотную (предупреждение);
  - `angle` — угол раскоса вне 30–60° (EC3/CIDECT);
  - `dbl` — двойной индивидуальный запил (>2 градусов на деталь);
  - `nodefit` — тела в узле не запилены друг к другу (модель материала
    конца как в `buildFullModel`, сканирование точек тела; контакт граней
    с запасом 0.5 мм не считается пересечением); hint: gap-узел ≥ t₁+t₂
    либо нахлёст ≥25%.
- Ошибки коллизий/«висит» блокируют, предупреждения — свёрнуты в `<details>`
  в начале модалки раскроя.

## Заготовки и спецификация

- Длина заготовки: `Ls = La + endLenAdd(A) + endLenAdd(B)` (см. знаки выше).
- Заготовки каталога: стандартная длина поставки `sell_len_m` (12 м),
  цена `price_rub_m` (₽/м), масса `mass_kg_m` (кг/м).
- Раскладка: стержни группируются по сечению и штабелю (одинаковый профиль),
  режут 12‑метровые штабы; покупная длина = Σ штабов; отход = покупка − нужное.
- **Группировка одинаковых деталей** (`cutGroups()`, шаг 3): ключ
  `(sec, Ls, запил A, запил B)` → позиции **Д-1…Д-n** со сквозной нумерацией —
  одна логика для модалки и отчёта (номера совпадают во всех разделах).
  Таблица: `поз | кол | детали | L ось | +A | +B | L загот | запилы`, CSV.

## Отчёт (v53, разделы 6–8 в 31-report.js)

1. **Чертежи запилов** (`svgCutPos`) — по одному чертежу на позицию Д-n:
   заготовка в масштабе (ось, узлы со знаковым выносом, линии реза, размеры)
   + два укрупнённых торца с истинными углами.
2. **Схемы стыковки узлов** (`jointGroups`/`svgJoint`) — две проекции
   (фасад XZ + план XY), цвета: красный — основной, серый пунктир —
   проходной, зелёный — ветви; одинаковые схемы сгруппированы.
3. **План сборки и проверки** (`svgAsmPlan`) — таблица этапов (детали/позиции),
   вид XZ с окраской по этапам, таблица всех проверок.

## Примечания

- Прямоугольные профили всегда ориентированы широкой стороной вертикально
  (конвенция редактора), отсюда ось запила считается в реальном базисе сечения.
- Детектор работает и для host‑разделённых стержней (куски `id#k`):
  стыки считаются по кускам, таблица агрегируется по стержню.
- Эталон FNV-хеша раскроя (регрессия формулы Ls): **3062305659**
  (старый 161705799 ушёл с фиксом знака выноса T/nest).
