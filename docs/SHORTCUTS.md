# Горячие клавиши, панели, режимы

## Режимы (вкладки)

| Клавиша | Режим |
|---|---|
| F2 | Каркас (модель) |
| F3 | Нагрузки / расчёт / подбор сечений |
| F4 | Раскрой |
| F5 | Отчёт (HTML) |
| Enter | закрыть чертёж (план) |
| Esc | каскадная отмена: модалка → меню → drag → вставка → цепочка инструмента → план → выделение |

## Инструменты

| Клавиша | Инструмент |
|---|---|
| V | выбор |
| N | узел |
| O | опора (ряд опор: параметрический ряд по X) |
| L | плоскость (по 3 узлам) |
| M | измерение |
| X | узлы на пересечениях стержней (общие host‑узлы, идемпотентно) |
| B | полная модель из профилей (вкл/выкл «Профили») |
| P | плоскость по выделению (fit‑вид) |
| F | вписать модель (fitAll) |
| 1…9 | типы стержней: 1 верхний пояс, 2 нижний, 3 раскос, 4 диагональная связь, 5 стойка, 6 колонна, 7 раскос плоскостной, 8 прогон, 9 произвольный |
| H | скрыть выделенное (дерево: eye) |

## Ctrl/Cmd

| Комбинация | Действие |
|---|---|
| Ctrl+Z / Ctrl+Shift+Z | отмена / повтор |
| Ctrl+Y | повтор |
| Ctrl+S | быстрое сохранение (localStorage) |
| Ctrl+O | список сохранений |
| Ctrl+E | экспорт JSON |
| Ctrl+C / Ctrl+V | копирование / вставка выделенного |
| Ctrl+D | клонирование выделенного (ось/шаг из панели) |
| Ctrl+G | группировка |
| Del | удалить выделенное |
| F1 | справка (процесс, методика, отказ от ответственности) |

## Панели

- **Слева** — дерево модели (стержни/узлы/плоскости, глазки скрытия).
- **Справа** — панель инструмента (подсказка, точная установка X/Y,
  параметрический ряд опор), панель свойств выбранного (сечение, материал,
  тип, длины), параметры (шаг сети, привязки, клонирование с шагом).
- **Расчёт (F3)** — состав нагрузок (собственный вес, снег: регион/μ, ветер:
  район/местность, эксплуатационная, множитель), кнопка РАСЧЁТ;
  **подбор сечений**: критерий (масса/цена), ползунок «Макс. использование»
  UR 0.3–1.0, f ≤ L/200, кнопка ПОДБОР СЕЧЕНИЙ (Ctrl+Z — откат);
  отображение: тепловая карта (UR/N/M/прогибы), палитра от мин/макс,
  деформированная схема (галка + авто/ручной масштаб); вывод: сводка,
  топ‑стержни, реакции, кнопки отчёта.
- **Раскрой (F4)** — таблица торцов/запилов/вложений по стержням,
  спецификация заготовок (покупка/отход).
- **Отчёт (F5)** — HTML: снимки видов, схемы, расчёт, раскрой, смета.

## Мышь

ЛКМ — инструмент/выбор; drag по узлу — перемещение; рамка (marquee) —
рамочное выделение; ПКМ — контекстное меню (скрыть/показать/изолировать,
операции); колесо — зум к курсору; средняя/правая+drag — пан; drag по пустому —
орбита; двойной клик по стержню/плоскости — вход в чертёж.
