# Методика расчёта

## Модель

Пространственная стержневая FE‑модель: каждый стержень — прямой брус
(балочный элемент) с 6 степенями свободы в каждом конце (12 DOF),
узлы общие. E = 206 000 МПа, G = 79 000 МПа. Опора (`type:'support'`) —
заделка всех 6 DOF. Геометрически линейный расчёт (малые перемещения).

### Декомпозиция по host‑узлам

Расчётная модель **не изменяет основную**: перед сборкой каждый стержень
режется поперечными узлами‑носителями (host‑узлы инструмента X и узлы внутри
стержня, допуск HOST_TOL). Куски входят в FEM через общие узлы (имена вида
`rod.id + '#'`), после решения агрегируются в строку стержня:
Ncomp/Nt/Mmax/UR/defl — максимум по кускам, L — суммарная длина.
Нагрузки (снег/эксплуатационная) прикладываются к кускам с корректной
долей длины.

## Нагрузки (СП 20.13330-2016)

Единицы: N/mm на элемент; координаты мм; S, W — кПа.

- **Собственный вес**: `q = m·9.81/1000·1.05` (γf = 1.05), вертикально −Z.
- **Снег**: `S = S0(регион) · μ`; S0: регион 1–8 = 0.5…4.0 кПа;
  γf: регионы 1–3 → 1.4, 4–6 → 1.5, 7–8 → 1.6.
  μ по уклону ската: ≤25° → 1, 25–60° → 1.25, >60° → 0.
  Площадь набирается **по горизонтальной проекции**: стержни кровельного слоя
  группируются в плоскости скатов (нормаль n, уклон по n.z), выбирается
  «скин» — слой, несущий кровлю (прогоны; если их нет в плоскости — верхние
  пояса). Прогоны скина делятся на ряды по плановой координате (направление,
  перпендикулярное коньку), каждому ряду — ширина приведения: половина
  расстояний до соседних рядов, **крайние ряды добраны до плановых границ
  ската** (карниз/конёк) — полосы покрывают план ската ровно один раз.
  Интенсивность вдоль наклонного стержня умножается на `Lh/L = cos θ`
  (нормативная нагрузка задаётся на горизонтальную проекцию).
  Нижний пояс, раскосы, колонны снег напрямую не получают: путь
  прогон → узел → каркас.
- **Ветер**: `w = W0(регион) · ce(z) · γf 1.4 · b/1000`; W0: 0.17…0.9 кПа;
  ce(z) по местности A–D; на кровле — всас; на плоскости рам — по шагу
  соседних рам; ширина приведения по геометрии рядов.
- **Эксплуатационная**: 0.4 кПа (γf 1.2) по кровельным полосам +
  1 кН вертикально в узлы скина.
- Общий множитель `calc.factor` — на все нагрузки.

## Проверки (СП 16.13330, упрощённо)

Для каждого стержня по envelope (m₂,m₃ — локальные оси изгиба):

- Сжатие + изгиб: `UR = N/(φ·A·Ry) + (|M₂|/Wy + |M₃|/Wx)/Ry · (1 − 0.8·n)`,
  где `n = N/(φ·A·Ry)`, φ(λ) — продольный изгиб, λ = L/i_min.
- Растяжение + изгиб: `UR = N/(A·Ry) + (|M₂|/Wy + |M₃|/Wx)/Ry`.
- Изгиб двуосный — оба сечения (для прямоугольных труб Wx ≠ Wy).
- UR > 1 — стержень помечен «не проходит».
- Прогиб стержня: `d = 5qL⁴/(384EI) − M·L²/(16EI)` по каждой локальной оси
  (прогиб идёт в направлении нагрузки) + узловое перемещение;
  проверочный лимит f ≤ L/200.

## Авто‑подбор сечений «равная прочность»

Цель — выровнять использование (UR) всех типов стержней к целевому верху
`T` (ползунок «Макс. использование», 0.3–1.0), минимизируя массу/цену:

1. Стартовая точка — текущие сечения по типам (самое частое сечение типа);
   кандидаты — квадратные/прямоугольные трубы каталога, сортировка по массе
   (или цене).
2. Полный пересчёт FEM на каждом шаге.
3. Если тип превышает T (UR>T) или жёсткий лимит f>L/200 — тип поднимается
   на шаг вверх по каталогу (худший первым).
4. Если всё под целью — самый разгруженный тип пробно опускается на шаг;
   при нарушении — откат и блокировка понижения этого типа.
5. Итог: все типы ≤ T и максимально близко к T («равная прочность»);
   при неудаче — восстановление исходных сечений; отчёт по типам
   «UR до → после», масса, цена, число пересчётов; Ctrl+Z — полный откат.

## Реакции

Опорные реакции = сумма усилий в заделанных DOF (R = −(K·u + f0) опорных
рядов). Контроль равновесия: ΣRz = ΣFz приложенных.

## Деформированная схема

Тела профилей разворачиваются по изогнутой осевой:
`u(x) = lerp(uA + θA×(x−pA), uB + θB×(x−pB)) + (e2·d2 + e3·d3)·sin(πx/L)·scale`.
Авто‑масштаб = 6% размера модели / max прогиб стержней (узлы у заделок — 0).
В плане прогибы (перпендикулярны экрану) рисуются эпюрой perpendикулярно осям.
