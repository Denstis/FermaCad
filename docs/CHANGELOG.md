# Changelog

Формат версий — версии сборки (`?v=NN` в UI). `vNN-baseline` — git‑tag эталона.

## v48 (2026-11-16)
- Авто‑подбор сечений — целевая **«равная прочность»**: ползунок «Макс. использование» (UR‑цель 0.3–1.0). Старт от текущих сечений: перегруженные типы (UR>цели или f>L/200) поднимаются на шаг (худший первым), самый разгруженный пробно опускается и остаётся, если весь каркас проходит. Прогиб f≤L/200 жёсткий, полный пересчёт на каждом шаге, Ctrl+Z. Проверено на модели 130 стержней: сталь −36 %, UR max точно на цели 0.70.
- Стержни без явного сечения (дефолт по типу, напр. раскосы) участвуют в подборе и в отчёте (масса/цена больше не 0).

## v47 (2026-11-16)
- Детектор коллизий полной модели с **глубиной вложения**: ветви, влезающие в
  полость полой трубы, вложены до внутренней стенки (`nest`), остальные
  обрезаются впритык к наружной (`T`, sOut box-расчёт по базису сечения main).
  Призмы «Профилей» обрезаются, сварное кольцо — по плоскости торца/стенки.
  Раскройный таб показывает «вложено в осн. …, глубина N мм» / «не входит в
  полость — впритык».
- Авто‑подбор сечений переписан на **«равную прочность»**: ползунок
  «Макс. использование» UR 0.3–1.0; перегруженные типы поднимаются, самый
  разгруженный пробно опускается (с откатом и блокировкой); f≤L/200 жёсткое;
  полный пересчёт FEM на каждом шаге; отчёт по типам «UR до→после», масса/цена,
  итерации.
- Убрано: GuiRoof.rar, Qwen‑образцы (в локальный `_samples/`, вне git),
  мёртвый код `fP`, `optPassOK`.
- Документация: README переписан, docs/ (ARCHITECTURE, CALC, CUTTING, DATA,
  SHORTCUTS, CHANGELOG, AGENTS), LICENSE.md.
- Репозиторий: push в `github.com/Denstis/FermaCad` (main + все tags).
