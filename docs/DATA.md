# Данные: материалы, сечения, цены

Каталог — `js/27-data.js` (`NR_SECTIONS`, марки стали), перенесён из проекта
NewRoof, сверен с нормами.

## Марки стали (ГОСТ 27772-2015)

Расчётные сопротивления — нормативные / 1.025 (коэффициент надёжности по
ГОСТ 27772):

| Марка | толщина, мм | Ry, МПа | Ry (изг.) | Ry_s (срез) | Rz (распр.) |
|---|---|---|---|---|---|
| С235 | 2…20 | 230 | 230 | 133 | 230 |
| С245 | 2…20 | 240 | 240 | 139 | 240 |
| С345 | 2…17 | 335 | 335 | 193 | 335 |

- `Ry_s = Ry/√3`, `Rz` — расчётное сопротивление растяжению (введено в расчёты
  для проверки растянутой зоны: `N/(A·Rz)`-логика растяжения+изгиба).
- E = 206 000 МПа, G = 79 000 МПа, ρ = 7 850 кг/м³.
- Сжатие через φ(λ), λ = L/i_min — таблица φ СП 16.13330 (реализована в
  `phiBar`).

## Сечения: стальные гнутые профили (ГОСТ 30245-2003 и др.)

- `shs` — квадратные трубы (50×50…200×200, t 2…8);
- `rhs` — прямоугольные трубы (80×60…300×200, t 3…8);
- для каждого: `b_mm, h_mm, t_mm`, площадь `A_cm2`, `Ix/Iy` (см⁴),
  `Wx/Wy` (см³), `ix/iy` (см), масса `mass_kg_m` (кг/м),
  длина поставки `sell_len_m` (12 м), цена `price_rub_m` (₽/м).
- Инерция/моменты замкнутого контура: `J = 2·A²·m·t/Pm` (тонкостенное
  приближение), двутавровые/швеллерные контуры — по каталогу.
- Моменты сопротивления для rhs разные по осям: 120×80 — Wx 40.9 см³,
  Wy 51.5 см³ (проверено), поэтому двуосный изгиб |M₂|/Wy + |M₃|/Wx обязателен.
- Конвенция ориентации прямоугольных труб в редакторе: **широкая сторона b —
  вертикально** (по глобальной Z для горизонтальных стержней).

## Цены

`price_rub_m` — розничные ₽/м по прайсу «1металлбаза» (актуален на момент
переноса из NewRoof). Смета = Σ длина×цена + пересчёт на подобранных сечениях.
Цены — справочные, не оферта.

## Хранение

Стержень хранит `sec` (id сечения) и `mat` (марка); при `sec = null` —
наследуется `SEC_DEFAULTS[тип]` (18-demo.js). Сортамент/материалы — единый
источник `NR_SECTIONS`; проверка актуальности: `node --check` + сверка
mass/Ix/W с таблицами ГОСТ при пополнении каталога.
