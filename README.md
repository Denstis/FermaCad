# ФЕРМА·CAD — редактор стержневых конструкций

Одностраничный 3D/2D‑редактор стальных каркасов: сварной пространственный каркас,
фермы, колонны, прогоны, связи — от модели до раскроя и HTML‑отчёта.
Без бэкенда: HTML + модули‑скрипты + three.js (CDN). Автор: **DENstis** (Denstis@gmail.com).
Исходно был одним файлом (156 КБ); проект разбит на модули по доменам,
референсные образцы лежат локально в `_samples/` (вне репозитория).

## Возможности

- **Каркас** — стержни 9 типов (верхний/нижний пояс, раскосы, связи, диагональные
  связи, стойки, колонны, раскосы плоскостные, прогоны, произвольный), узлы,
  опоры (заделка 6 DOF), плоскости, размеры, инструмент **«узлы на пересечениях
  стержней» (X)**, клонирование с шагом, точная установка, дерево модели.
- **Чертёж (план XY)** — 2D‑план с размерами, вертикальные нагрузки стрелками,
  эпюра прогибов перпендикулярно осям.
- **Нагрузки и расчёт (F3)** — собственный вес (γf 1.05), снег по СП 20.13330
  (регионы 1–8, μ по уклону, γf 1.4–1.6, полосы по плану ската с краевыми
  доборами до карниза/конька), ветер (w0 по району, ce(z), местности A–D,
  всас на кровле), эксплуатационная 0.4 кПа + 1 кН в узел. Полная 3D FEM:
  стержни автоматически делятся по host‑узлам без изменения модели;
  N, M₂, M₃, прогибы, реакции.
- **Тепловые карты** N / M / прогибы / UR — по стержням, частям, узлам и телам;
  палитра 0→max или от текущих **мин/макс**. Деформированная схема — тела
  профилей по **изогнутой осевой** (авто‑масштаб по max прогибу).
- **Авто‑подбор сечений «равная прочность»** — ползунок целевого UR (0.3–1.0):
  перегруженные типы поднимаются, самый разгруженный пробно опускается;
  полный пересчёт каркаса на каждом шаге; f ≤ L/200 — жёсткое ограничение;
  критерий масса/цена; Ctrl+Z откат.
- **Профили (B)** — полная 3D‑модель из профилей: прямоугольные трубы всегда
  широкой стороной вертикально; сварные контуры стыков; **детектор коллизий
  с глубиной вложения**: ветви, влезающие в полость трубы, вложены до внутренней
  стенки; остальные обрезаются впритык к наружной — торчащих торцов нет.
- **Раскрой (F4)** — торцы: опора 90°, проходной без запила, угол по биссектрисе
  (90°→45°, α→90°−α/2), T‑подрез, вложение в полость; заготовки, покупка, отход.
- **Отчёт (F5)** — HTML: снимки видов, SVG‑схемы элементов, топ‑стержни, реакции,
  раскрой, смета, состав сечений, методика.
- Версионирование: чип `vNN` в UI + cache‑bust `?v=NN` у каждого скрипта.

## Запуск

```bash
python -m http.server 8150 --bind 127.0.0.1
# открыть http://127.0.0.1:8150/index.html
```

Можно просто открыть `index.html` (three.js r128 с CDN, работает и с `file://`).
После обновления версии — Ctrl+F5.

## Структура

```
index.html        — разметка (топбар, тулбар, viewport, панели, модалки)
css/style.css     — все стили
js/  (32 модуля, порядок загрузки = порядок зависимостей)
  00-util.js        утилиты: $, clamp, fmt, esc, debounce, uid, V3, download
  01-icons.js       SVG-иконки + fillIcons
  02-types.js       типы стержней (TYPES), цвета, TOOL_DEFS
  03-state.js       всё состояние: модель M, выделение sel, params, камеры ctrl/pl, кэш материалов
  04-scene3d.js     инициализация THREE: рендерер, свет, нав-куб, спрайты, примитивы
  05-model.js       CRUD узлов/стержней, плоскости, клон/копия/вставка, split, shared hosts
  06-history.js     serialize/deserialize, undo/redo, автосохранение, afterChange
  07-scenebuild.js  перестроение сцены, материалы выделения, тень-фрустум
  08-grid.js        сетка чертежа, размерные линии, измерения
  09-camera.js      орбита/пан/зум, плавные камеры, fitAll/fitBox
  10-picking.js     picking лучом, привязки в чертеже (snapPlan) и 3D (snap3D)
  11-ghost.js       призрачная геометрия инструментов, направляющие, живой бейдж координат
  12-tools.js       setTool, подсказки, выделение, обработка клика инструмента
  13-pointer.js     drag/рамка/пан/орбита/пинч, перетаскивание узлов, hover
  14-plan.js        режимы чертежей: XY, стержень, плоскость; выход в 3D
  15-ctxmenu.js     контекстные меню ПКМ, скрыть/показать/изолировать
  16-modals.js      модалки и тосты (клон, split, группа, справка)
  17-storage.js     сохранения в localStorage (fc.auto), экспорт JSON/OBJ, импорт
  18-demo.js        демо-модель «Ангар 12×6 м», SEC_DEFAULTS
  19-tree.js        дерево модели
  20-props.js       панель свойств (карточки сущностей + действия + поля)
  21-coach.js       обучающий чек-лист
  22-params.js      панель параметров: синхронизация и биндинги
  23-toolbar.js     тулбар и топбар
  24-cube.js        нав-куб (грани/рёбра/углы)
  25-keys.js        горячие клавиши
  26-app.js         RAF-цикл и boot()
  27-data.js        каталог сечений NR_SECTIONS и материалов (ГОСТ 27772)
  28-calc.js        FEM solveFrame, нагрузки СП 20, UR СП 16, тепловые карты,
                    деформации, раскрой, авто-подбор сечений, панель расчёта
  29-fullmodel.js   полная модель из профилей: контуры, endInfo (стыки + вложение),
                    призмы с обрезкой по глубине вложения, сварные контуры
  30-xnodes.js      узлы на пересечениях стержней (segClosest, shared hosts)
  31-report.js      HTML-отчёт (снимки, схемы, смета) + изогнутые тела деформаций
```

Порядок загрузки скриптов в `index.html` = порядок зависимостей (общая глобальная
lexical-среда классических скриптов): состояние объявлено в `03`, функции вызываются
только во время работы, `boot()` живёт в `26-app.js`.

## Формат проекта

Сохранение — JSON (узлы, стержни, плоскости, группы, параметры); автосейв в
localStorage (`fc.auto`). Экспорт — Ctrl+E. Импорт — диалог «Открыть»
(файлы `.json`/`.framecad.json`).
